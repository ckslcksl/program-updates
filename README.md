# 픽셀플로우

- Windows에서 이미지와 글씨를 인식하고, 설정한 조건에 따라 동작을 실행하는 프로그램입니다.
- 실행할 때 인터넷 연결과 유효한 기기 승인이 필요합니다.
- Discord 등 외부 서비스의 이용약관, API 제한 및 수신자의 메시지 수신 설정을 준수해야 합니다. 원치 않는 메시지 전송에 사용해서는 안 됩니다.
- 배포자의 사전 서면 허가 없이 암호화 데이터의 복호화, 토큰·키·인증정보의 추출, 이를 위한 분석·변조 또는 보호 기능의 우회를 금지합니다.
- 법령 위반, 무단 접근, 사기, 스팸, 괴롭힘 등 불법적인 목적 또는 행위에 사용하는 것을 금지합니다.
- 실행 시 자동으로 최신버전과 비교해 업데이트합니다.
- 최초 실행 시 24시간의 임시 승인 사용자 상태입니다.

[최초 다운로드](https://github.com/ckslcksl/program-updates/releases/tag/setup)

## v1.0.8 업데이트

- 클릭 액션에 **비활성 클릭 (물리 입력 격리)** 옵션을 추가했습니다.
- 프로그램의 클릭 버튼과 좌표를 유지하면서 다른 창에서 타이핑한 키가 대상에 함께 들어가는 현상을 줄입니다.
- DK와 Maple에서 클릭 및 I·A·5 입력 격리를 확인했습니다.
- 새 옵션은 클릭 전용입니다. 키 입력·유지·떼기는 기존 입력 방식을 사용하세요.
- 기존 규칙과 개인 설정은 유지됩니다. 대상에 따라 호환성이 다를 수 있습니다.

클릭 액션의 입력 방식에서 새 옵션을 선택하고 대상 창을 비활성으로 두세요.

[최신 버전 다운로드](https://github.com/ckslcksl/program-updates/releases/latest)

## v1.0.9 업데이트

- 새 클릭의 기본값이 **비활성 클릭 (물리 입력 격리)**로 바뀌었습니다.
- 기존 클릭 액션도 처음 실행할 때 같은 방식으로 전환하며 변경 전 복구본을 보관합니다.
- 현재 목록·저장된 규칙 목록·마지막 사용 설정에 적용합니다. 키 입력·유지·떼기 방식은 유지합니다.
- 자동 전환은 승인된 PC에서 한 번만 수행하며, 이후 직접 선택한 입력 방식은 유지됩니다.


## v1.0.12 업데이트 · 게이지 감시

- 체력·마력 게이지의 남은 %가 설정 조건을 만족하면 액션을 실행합니다.
- 고정 아이콘·글자로 게이지 표시를 확인하며, 미표시·인식 불확실 시 실행하지 않습니다.
- 게이지가 사라지거나 조건을 벗어나면 남은 액션을 취소합니다.
- 자동·오류 종료 시 입력 정리 완료를 확인하는 보완도 포함했습니다.

**게이지 규칙 +** → 영역·색상·표시 확인 이미지 등록 → % 조건 설정 → 실행 액션 추가.
숫자가 겹치면 글씨 위나 아래의 얇은 띠를 게이지 전체 길이로 지정하세요.
