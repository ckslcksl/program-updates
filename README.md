# 

- Windows에서 이미지와 글씨를 인식하고, 설정한 조건에 따라 동작을 실행하는 프로그램입니다.

- 실행할 때 인터넷 연결과 유효한 기기 승인이 필요합니다.

- Discord 등 외부 서비스의 이용약관, API 제한 및 수신자의 메시지 수신 설정을 준수해야 합니다. 
원치 않는 메시지 전송에 사용해서는 안 됩니다.

- 배포자의 사전 서면 허가 없이 암호화 데이터의 복호화, 토큰·키·인증정보의 추출,
이를 위한 분석·변조 또는 보호 기능의 우회를 금지합니다.

- 법령 위반, 무단 접근, 사기, 스팸, 괴롭힘 등 불법적인 목적 또는 행위에 사용하는 것을 금지합니다.

- 실행 시 자동으로 최신버전과 비교해 업데이트 합니다.

- 최초 실행시 24시간의 임시 승인 사용자 상태입니다.
